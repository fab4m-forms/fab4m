Fab4m works with both React and Svelte. Pick your framework and install the core
package alongside the matching renderer.

## Install fab4m

<Tabs>
  <TabItem label="React" icon="seti:typescript">
    ```bash npm install --save @fab4m/fab4m @fab4m/react ```
  </TabItem>
  <TabItem label="Svelte" icon="seti:svelte">
    ```bash npm install --save @fab4m/fab4m @fab4m/svelte ```
  </TabItem>
</Tabs>

## Create your first form

The form definition is the same regardless of framework; only the rendering differs.

<CodeExample reactCode={FirstFormSource} svelteCode={FirstFormSvelteSource}>
  <FirstFormExample client:load />
</CodeExample>

You now created your first form!

We first created the form definition, then used the `StatefulFormView` component
to render it. `StatefulFormView` handles the form's internal state management, so
you don't have to worry about that yourself.

Head over to our [step by step guide](/guides/define-a-form) to learn about more complex use cases.
