A password widget with an extra confirmation field that lets the user verify
they typed the password correctly. A "The password matches!" hint is shown when
the two values are equal, and the confirm input gets a `pattern` attribute that
matches the entered password.

The `confirmTitle` widget setting controls the label of the confirmation input
(it defaults to `"Confirm password"`).
