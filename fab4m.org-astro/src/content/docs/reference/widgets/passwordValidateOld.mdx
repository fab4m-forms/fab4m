# Password validate old widget

A password widget with three inputs: the old password, the new password, and a
confirmation of the new password. A "The password matches!" hint is shown when
the new password and confirmation are equal, and the confirm input gets a
`pattern` attribute that matches the new password.

The widget settings `confirmTitle` (defaults to `"Confirm password"`) and
`oldPasswordLabel` (defaults to `"Old password"`) control the labels of the
confirmation and old-password inputs.
