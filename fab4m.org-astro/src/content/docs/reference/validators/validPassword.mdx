The password validator validates that a password follows the specified settings:

* `minLength` — the minimal length of the password.
* `requiredLetter` — the password must include at least one letter.
* `requiredNumber` — the password must include at least one number.
* `requiredSpecialChar` — the password must include at least one special character.

When the widget renderer registers the password validator info component (as the
default `allWidgetsRenderer` does in both `@fab4m/react` and `@fab4m/svelte`),
the relevant rules are shown next to the input with a checkmark for each rule
that passes.
