# Valid old password

The validate old password validator validates that the old password a user
provides matches the real old password. The validation is performed through an
async callback that should return `true` if the password is equal and `false`
otherwise.

**Note:** The old password validator does not work within JSON Schema since it
needs to perform an external validation. It also doesn't work when used inside
of rules.
