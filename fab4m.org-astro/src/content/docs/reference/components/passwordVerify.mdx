# Password (with verification)

* **Data type:** PasswordVerifyData
* **JSON Schema data type:** object

Let users input a password along with a confirmation field that verifies the
password is correct.

The confirm field's `confirmTitle` widget setting controls the label of the
confirmation input (see the [password verify widget](/reference/widgets/passwordVerify)).
