* **Data type:** PasswordValidateOldData
* **JSON Schema data type:** object

Let users input a new password, verify it, and validate their old password.
Use this when you want a user to change their password while making sure they
know the current one.

The widget settings `confirmTitle` and `oldPasswordLabel` control the labels of
the confirmation and old-password inputs (see the
[password validate old widget](/reference/widgets/passwordValidateOld)).
