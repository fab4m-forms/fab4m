## Migration Notes

1. **Sidebar auto-generation:** Docusaurus uses `autogenerated` from directory structure — Astro/Starlight sidebar config will need to reflect this order
2. **Live code blocks:** Docusaurus `@docusaurus/theme-live-codeblock` plugin — needs equivalent in Astro (e.g., interactive components with client islands)
3. **Docs use MDX:** `.mdx` files require MDX support in Astro
4. **Interactive examples:** `Example.tsx` uses `BrowserOnly` — needs `client:only` directive in Astro
